# Bartop Arcade

Catálogo de los juegos probados en mi bartop (Raspberry Pi 3 + RetroPie, panel Xin-Mo para dos jugadores).

Web: https://vicente-priego-aviles.github.io/bartop-arcade/

Esta web la genera `_scripts/generar_web.py` desde el vault de Obsidian del proyecto: no editar los HTML a mano.
No contiene ROMs. Las portadas, nombres y marcas de los juegos pertenecen a sus propietarios.
